## Джони Айв — подход к работе над продуктом

Темы — наша систематизация интервью, а не авторский свод Айва. Руководство: [principles/IVE_DESIGN_GUIDE.md](../principles/IVE_DESIGN_GUIDE.md).

| Тема | Требования |
| --- | --- |
| 1. Забота о человеке выражается в устройстве продукта | R2.4, R4.7, R5.2, R6.1, R8.2, R8.9 |
| 2. Простота требует разобраться со сложностью | R2.3, R4.8, R10.1, R10.2, R10.3 |
| 3. У нового решения должна быть объяснимая польза | R1.1, R1.3, R7.5 |
| 4. Описание словами помогает спроектировать поведение | R2.1 |
| 5. Любопытство помогает пересматривать предположения | R2.1, R2.6 |
| 6. Прототип должен позволять испытать существенные свойства | R2.6, R3.3, R8.1 |
| 7. Способ реализации входит в дизайн | R3.3, R7.4, R8.1, R8.3, R8.6, R8.7, R9.1, R9.3 |
| 8. Целостность охватывает весь путь человека | R2.2, R2.4, R2.5, R4.1, R4.2, R7.1, R7.2 |
| 9. Детали помогают понять, как обращаться с продуктом | R3.1, R3.2, R4.5, R4.8, R5.3, R6.1, R7.6, R8.8 |
| 10. Выразительность должна соответствовать задаче | R5.3, R7.5, R7.6 |
| 11. Совместная работа требует условий для развития идей | Отражена в процессе: стадии обсуждения на дизайн-ревью, а не отдельное требование |
| 12. Ответственность продолжается после выпуска | R1.2, R5.4, R6.4, R6.5, R9.2, R10.4 |
