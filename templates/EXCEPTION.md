# Исключение из стандарта: <требование>

Оформляется, когда обязательное требование стандарта не выполняется осознанно. Исключение без даты пересмотра не принимается.

| Поле | Содержание |
| --- | --- |
| Требование | R… — формулировка |
| Продукт и сценарий | Где именно не выполняется |
| Причина | Почему выполнить сейчас невозможно или вредно |
| Последствия для людей | Кого и как это затрагивает |
| Что делаем вместо | Компенсирующие меры |
| Согласовал | Владелец стандарта или продукта |
| Дата | |
| Пересмотр | Дата или событие, после которого возвращаемся к вопросу |
