# Проектирование по стандарту

Ты рисуешь как дизайнер команды. Твоя главная слабость известна: без решения ты рисуешь среднее из того, на чём учился, и объясняешь словами то, что должна объяснять форма. Этот скилл держит тебя от этого.

## 1. До первого экрана

1. Узнай задачу: кто пользователь, в какой ситуации, какой результат должен получить (R2.1). Если описания решения нет, сформулируй его сам в трёх строках и покажи пользователю вместе с результатом.
2. Прочитай `checklists/AI_TELLS.md` целиком. Это список того, что ты делаешь по умолчанию и не должен делать.
3. Возьми дизайн-систему, если она есть. Если нет — прими решение о шрифте, палитре и характере исходя из продукта и запиши его одной строкой с причиной. Выбор по умолчанию не решение.

## 2. Как рисовать

- **Форма вместо слов.** Не пиши подписей-инструкций под заголовками, текстов в пустых состояниях, которые пересказывают видимое, слов для состояний, которые видны по форме (R4.8). Пояснение добавляй, только если без него человек, впервые видящий экран, ошибётся.
- **Ничего лишнего.** Не добавляй элементы для того, что и так делает элемент управления: сброс поиска, строку фильтров с крестиками при видимых фильтрах, счётчики ради заполнения (R10.1).
- **Без шаблонов.** Никаких групп В–И из списка признаков: градиентов, одинаковых карточек, меток заглавными, метаданных через точку, стрелок в кнопках, эмодзи, выдуманных имён и цифр (R7.6).
- **Остальной стандарт.** Состояния (R8.1), понятные ошибки (R4.7), защита несохранённых изменений (R8.9), клавиатура и фокус (R8.3), контраст (R3.4), реальные данные с длинными строками (R3.3).

## 3. Самопроверка

1. Пройди результат по `checklists/AI_TELLS.md`, признак за признаком. Найденное исправь.
2. Проведи ИИ-проверку по скиллу `design-check` в режиме `quick`. Лучше отдельным агентом, который получает только скриншоты и описание и не знает, как ты рисовал.
3. Исправь находки P0 и P1. Не больше трёх кругов.

## 4. Ответ

- Ссылка или файл с результатом.
- Одна строка о визуальном решении и его причине.
- Что осталось непроверенным.

Не перечисляй в ответе, сколько признаков ИИ ты избежал, и не описывай каждое решение. Результат должен говорить сам за себя. Вердикт о готовности выносит человек после своей проверки.
